# Example App (React Native)

This workspace app is a minimal React Native integration for `@guardhouse/react-native`.

## Setup

1. Copy environment template:

```bash
cp .env.example .env
```

2. Fill your test identity server values in `.env`.

3. Install deps from workspace root or this package.

## Run

```bash
npm start
```

Then run `npm run android` or `npm run ios` in a separate terminal.
